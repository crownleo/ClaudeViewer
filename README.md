## 🚀 快速开始

### 第一步：从 Claude 导出数据

1. 打开 [claude.ai](https://claude.ai) 并登录
2. 头像 → **Settings** → **Privacy** → **Export data**
3. 点击 **Export**，等待邮件通知（通常几分钟内）
4. 邮件里给到的是一个 **`manifest-….json`**，打开它能看到 **5 个下载链接**——把这 5 个文件**全部下载下来**

> ⚠️ **manifest 里的下载链接只能用一次，点过即失效。** 请一口气把 5 个都下完；漏掉任何一个都无法补下，只能重新导出一次。

### 第二步：把下载到的文件放进同一个文件夹

**5 个 `.zip` 和那个 `manifest-….json` 放在一起，manifest 不要删。**

![导出文件夹](assets/files.png)

manifest 是判断**分片是否齐全**的唯一依据——对话量大时 `conversations` 会被切成 `-000` / `-001` / `-002` 多片，只有它知道总共该有几片。文件夹里应该有：

| 文件 | 内容 |
|---|---|
| `conversations-000.zip` | 全部对话（消息、时间戳、Thinking、附件） |
| `projects-000.zip` | 项目（名称、System Prompt、文档） |
| `memories-000.zip` | 个人记忆、项目记忆、记忆文件 |
| `feedback-000.zip` | Claude 官方月度回顾 |
| `light_metadata-000.zip` | 账户信息、登录记录 |
| `manifest-….json` | 清单（用于核对完整性，**请保留**） |

> 文件夹叫什么名字都行，建议用日期命名（如 `20260907-claude备份`）——它会成为档案库里这份档案的默认名称。

### 第三步：打开查看器

双击 `claude_viewer.html`，在浏览器中打开。

> **推荐浏览器**：Chrome / Edge
> Safari 可正常查看对话，但 PDF 导出功能受限

### 第四步：点「📁 选择导出文件夹」

在上传页点 **「📁 选择导出文件夹」**，选中第二步那个文件夹即可——5 个 ZIP 会被一次性解析完。**也可以直接把整个文件夹拖进页面。**

- 如果有分片没下全，会明确告诉你**缺哪个文件**
- 导入成功后可以选择 **「📚 存入档案库」**，把这次导出的原始文件整套存下来，之后随时切换、原样取回

> **旧版单 ZIP 依然完全支持**：2026 年 9 月之前导出的单个 `.zip`，直接拖进页面或点「选择单个文件」即可。

## 🧮 关于 LaTeX 公式渲染

ClaudeViewer 渲染的是 Claude **写在正文中的 LaTeX 文本**：

| 形式 | 是否渲染 |
|---|---|
| 行内公式 `$...$`、`\(...\)` | ✅ 渲染 |
| 块级公式 `$$...$$`、`\[...\]` | ✅ 渲染 |
| ` ```latex ` 代码块 | ⚪ 显示源码（代码块不渲染，符合预期）|
| 特殊 widget/可视化组件 | ❌ 导出无源码，显示友好提示 |

> 若希望公式确保能在导出数据中显示，可在对话时要求 Claude「用正文 LaTeX 写公式，不要用代码块或可视化组件」。

## 🔒 隐私说明

- **完全本地运行**：所有数据仅在浏览器内处理，不经过任何服务器
- **零外部网络请求**：v5.2 起 marked.js、JSZip、KaTeX 及其字体全部内联进单文件，打开页面不向任何 CDN 或第三方发起请求，可完全离线使用
- **CSP 强制隔离**（v6.0 新增）：页面头部声明 `default-src 'none'; connect-src 'none'`，由**浏览器强制**保证本页无法向任何服务器发送请求。这意味着即使将来不慎引入外部资源，或渲染层出现漏洞，你的对话内容也无法被传出去。副作用：对话正文里指向外部站点的 Markdown 图片将不再加载——这本就是一条跟踪与泄露渠道
- **默认不持久化**：除非你主动选择「保存到本地」
- **IndexedDB 缓存**：选择保存后数据存于此设备浏览器，仅本机可读，可随时清除
- **localStorage 存储**：收藏列表、标签、深色模式、缓存偏好、全空对话收起偏好、当前档案 id（不含对话内容）
- **档案库存储**：选择加入档案库的导出文件，其**原始字节**存于此设备浏览器的独立 IndexedDB（`claude_viewer_archives_v1`），仅本机可读，可随时逐份移除

> ### ⚠️ 关于「清除浏览器数据会不会把聊天删掉」
>
> **会。** 浏览器的「清除浏览数据 / 清除站点数据」会清空 localStorage 与 IndexedDB，本地缓存和档案库都在其中。这是浏览器行为，**任何网页都无法阻止**——能这么做正是「数据只在你手里」的另一面。
>
> 所以请这样理解各层的定位：
>
> | 层 | 作用 | 清浏览器数据后 |
> |---|---|---|
> | **磁盘 / 网盘上的原始导出文件** | **唯一真正的备份** | ✅ 不受影响 |
> | 档案库（原始字节） | 多份备份随时切换、可原样取回 | ❌ 丢失 |
> | 本地缓存（解析结果） | 免重复导入 | ❌ 丢失 |
>
> 三条实际建议：
> 1. **把 Claude 导出的原始文件留在磁盘或网盘上**，别导入完就删——档案库是「方便」，不是「备份」；
> 2. 档案库每份都有「**↓ 导出整套**」，可把原件逐字节取回磁盘，建议定期做一次；
> 3. v6.0 会自动向浏览器申请**持久化存储**（`navigator.storage.persist()`），获批后磁盘紧张时浏览器不会自动清理本站数据；档案库面板顶部会显示当前占用、配额与是否已获批。注意这只挡「浏览器自动清理」，挡不住用户手动清除。

## ❓ 常见问题：为什么我的对话「只剩一半」？

有用户反馈：一个对话前半段是一问一答，**后半段只剩自己在说话**，怀疑查看器丢了数据。

**结论：绝大多数情况下，那些回复在 claude.ai 上当时就是空的，并非查看器丢失。**

Claude 生成失败或被中断时，会在对话里留下一条**没有内容的空消息**——当时在网页上就是空白气泡。导出包会忠实地把它导出成 `"content": [], "text": ""` 的消息壳子（uuid、时间戳都在，只是没内容）。

v5.6 及更早版本会把这类空消息**静默过滤掉**，于是「Claude 当时没输出」被显示成「消息根本不存在」，看起来就像对话后半段只剩用户单方发言。

**v5.7 起已修复**：空消息改为显示灰色占位提示，对话卡片标注 `⚠ N`，全空对话也不再从列表消失。

### 自查方法

打开「统计」Tab，拉到底部的 **🩺 数据体检**，可以直接看到：

- 导出数据中有多少条空消息、占总量多少
- 哪些对话受影响最严重（空消息数、最长连续空）
- 空消息的按月分布——集中在个别月份说明是平台阶段性故障，而非你的数据或本工具的问题
- 一键复制体检报告，便于反馈

也可以手工核对：解压导出的 ZIP，用文本编辑器打开 `conversations.json`，搜索出问题的那段对话。如果看到一连串 `"content": [], "text": ""` 的 `assistant` 消息，就说明是原始对话本身就空——任何查看器都恢复不了，claude.ai 上当时也是空白的。

### 其他可能的「记录不全」

| 现象 | 原因 | 处理 |
|---|---|---|
| 整段历史缺失 | 导出文件名里的 `batch-0000` 表示分片，对话量大的账号会有 `batch-0001`、`batch-0002`… | 把所有分片 ZIP 一并导入 |
| 同一问题出现多个回答 | 编辑过提问或点过「重新生成」，导出包含全部分支 | 正常现象，非缺失 |
| 附件内容打不开 | 导出包只含附件的 uuid 引用，不含文件本体 | 平台限制，无法恢复 |

## 📋 版本历史

**v6.0** *(2026-09-08)*

> 从「查看器」迈向 [路线图](docs/ROADMAP.md) **阶段 2：本地归档器**。此前每次导入都是一次性的——看完就散，换一份备份就得推倒重来。v6.0 引入**档案库**：一份档案 = 一次完整导出的**原始字节**，多次备份可以并存、随时切换、原样取回。查看器从此不只是"打开一次"，而是**长期管理**你的 Claude 历史。

- **适配 Claude 新版分片导出** — 导出由单 ZIP 改为 `manifest` + 多个分类 ZIP，新增 `memories/{uuid}.json`、`reflections/`、`login_history.json`，全部支持；旧版单 ZIP 完全兼容
- **导出文件夹一键导入** — 选择或拖入整个文件夹即可，按 manifest 精确核对分片完整性，缺片明确报出文件名（下载链接一次性，早发现才来得及重导）；一个文件夹里放了多次备份时可选择打开哪一份
- **📚 档案库** — 保存多次导出的原始字节，支持切换、重命名、整套导出、逐个取出原件、逐份移除；收藏与标签**按档案隔离**，重开浏览器自动恢复上次的档案
- **导入后可直接存入档案库** — 保存弹窗新增「📚 存入档案库」，不必再去档案库把同一批文件重选一遍；档案名自动取 manifest 的导出时间
- **记忆文件不再被忽略** — `memory_files` 从旧版导出时代就在包里却从未被读取，现在自动列入「🧠 记忆」Tab，手工导入 `.md` 的步骤可以省了
- **新增「🪞 回顾」Tab** — 展示 Claude 官方生成的月度回顾：主题分布、时间去向、在拓展的能力、值得想一想
- **账户页新增登录记录** — 时间 / 地区 / 设备 / 方式
- **对话按 uuid 去重** — 分批导入、重复导入同一份不再堆叠
- **CSP 安全加固** — 页面声明 `default-src 'none'; connect-src 'none'`，把「零外部请求」交给浏览器强制执行；顺带堵住了对话正文里外部 Markdown 图片这条跟踪与泄露渠道
- **申请持久化存储** — 自动调用 `navigator.storage.persist()`，获批后磁盘紧张时浏览器不会自动清理本站数据；档案库面板显示占用、配额与获批状态
- 修复：补全 HTML 属性转义并清除全部内联 `onclick`（改为事件委托）、保存缓存的竞态与静默失败、对话回调竞态、两种模式 uuid 撞车取错对话；ZIP 导入开启 CRC32 校验以检出下载损坏
- 平台注入的系统提示（`injected_prompt_block`）以折叠块呈现，不再被丢弃
- 侧栏头部改为两行布局，标题与摘要不再被图标按钮挤到换行截断
- 新增 [`CONTRIBUTING.md`](CONTRIBUTING.md)，写明四条产品硬约束与验证清单

**v5.7** *(2026-08-05)*

- **空消息不再被静默丢弃** — Claude 当时生成失败留下的空消息改为显示灰色占位；此前会让对话后半段看起来只剩用户单方发言，被误认为查看器丢了数据
- **纯附件消息**（只上传文件、一个字没打）不再被判空丢弃，此前会连附件一起消失
- **全空对话不再从列表消失** — 默认收起以保持列表清爽，但过滤栏常驻「🫥 N 个全空对话已隐藏」标签，一点即展开
- 对话卡片新增 `⚠ N` 徽章标出空消息数
- 统计页新增 **🩺 数据体检** — 空消息数量/占比、受影响对话排行、按月分布，一键复制报告，不装 Python 也能自查
- MD / PDF 导出同步输出占位说明，不再只留一个光秃秃的标题

**v5.6** *(2026-07-23)*

- **接入 Claude Code 本地会话** — 上传页新增「📂 打开 Claude Code 本地对话」，选择 `.claude` 目录即可只读浏览 `projects/**/*.jsonl`
- 按项目分组，显示轮数 / Token / 大小 / 时间，标记活跃 ● 与 Agent 会话
- 跨项目全文搜索
- 通过归一化适配器复用主查看器的思考/工具折叠、导航条、对话内搜索与 MD 导出（MD 导出同步补全工具调用/结果）
- 双读取后端 — 安全上下文用 File System Access API 懒加载，`file://` 自动降级为文件夹选择器
- 与 Claude.ai 导出为独立可切换模式，侧栏 ⇄ 互切不清空。全程只读，绝不改动本地文件

**v5.5** *(2026-07-10)*

- 导出文件名以对话创建时间开头（如 `2026-05-26_1430_标题.md`），归档排序更自然
- 导出内容标题层级规范化 — 消息头改为二级标题，正文中 Claude 自带的标题整体降级，大纲不再混乱
- 附件代码围栏动态加长，内容含连续反引号时不再击穿格式，截断处增加提示
- 文档头新增创建/更新时间与消息数元信息
- 统计页月度柱状图修复拉伸变形（限制柱宽、只缩不放、最小柱高、悬停提示）
- 活动热力图加大格子并新增月份 / 星期标签

**v5.4** *(2026-07-05)*

- **移动端适配** — 手机上改为单栏「主从」布局：对话列表全宽，点开对话/统计/项目/记忆后详情全宽显示，返回即回列表
- 解决了此前手机上右侧详情被挤成一条竖缝、看不了对话的问题；桌面两栏布局不变

**v5.3** *(2026-07-04)*

- **个人记忆** — 导出 `memories.json` 里的全局个人记忆直接显示在「记忆」Tab（此前被忽略）
- **工具调用渲染** — `tool_use` / `tool_result`（联网、代码分析、MCP 等）以默认折叠块补全显示，修复用过工具的对话内容缺失
- **对话导航条** — 右侧竖条按提问定位，悬停展开、点击跳转

**v5.2** *(2026-07-01)*

- **舍弃 CDN，依赖全部内联** — marked.js、JSZip、KaTeX 及其字体全部打包进单文件，页面加载零外部请求、完全离线可用
- 解决了此前 CDN 在部分网络下加载慢 / 失败的问题
- 项目以 **GPL-3.0** 开源，封面与运行界面加入作者署名与版权声明

**v5.1** *(2026-06-28)*

- **一键复制** — 消息 / 思考过程 / 附件内容
- **间距优化** — 防止消息重叠、思考过程完整展示

**v5.0** *(2026-06-27)*

- 稳定整合发布：在 v4 系列全部功能基础上，包含 LaTeX 公式渲染、混合渲染模式、逐次搜索匹配、不支持组件友好提示

主要能力：
- 数据查看：ZIP/JSON/MD 导入，对话/项目/记忆/账户，混合渲染，思考过程，附件展示，代码块复制，LaTeX 公式
- 搜索：对话内逐次搜索 + 结果侧边栏 + 全局搜索（精准定位）
- 统计：概览卡片、月度柱状图、按天活动热力图（点击筛选）、消息排行榜
- 管理：收藏、标签、深色模式、IndexedDB 本地持久化
- 导出：单条 Markdown/PDF（含公式）、全部对话批量 ZIP

> 演进脉络：v1 对话查看与虚拟滚动 → v2 ZIP 导入与多类型数据 → v3 全局搜索与统计 → v4 搜索侧边栏、热力图、本地持久化、LaTeX、混合渲染 → v5 稳定整合发布 → v5.1 一键复制与间距优化 → v5.2 舍弃 CDN、依赖内联 → v5.3 个人记忆、工具调用、对话导航 → v5.4 移动端适配 → v5.5 MD 导出修复、统计图美化 → v5.6 接入 Claude Code 本地会话 → v5.7 空消息占位修复与数据体检 → v6.0 适配分片导出、档案库与 CSP 加固。
